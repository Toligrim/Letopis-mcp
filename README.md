# Летопись (Letopis) — движок архива и умного поиска по истории Telegram-чатов

Архив чатов в сыром JSONL + быстрый полнотекстовый поиск с русской морфологией +
качалка с менеджером. Основной сценарий: Claude Code читает архив через CLI `./tg`
и отвечает на вопросы по содержимому чатов (инструкция для агента — в `CLAUDE.md`
конкретного репозитория с данными).

Это только движок (код) — сами данные (архив, индекс, конфиг, сессия Telegram)
живут в отдельном репозитории и сюда не входят. Движок сам находит корень с
данными: при запуске `tg` ищет от текущей директории вверх папку, где рядом лежат
`config.toml` и `archive/` (или это явно задаётся переменной `TG_ROOT`). Поэтому
типовой способ подключить движок к конкретному архиву — положить в репозиторий с
данными скрипт-обёртку `./tg`, которая вызывает бинарник отсюда, например:

```sh
#!/bin/sh
exec "$HOME/projects/letopis/.venv/bin/tg" "$@"
```

и запускать `./tg ...` из корня репозитория с данными — код остаётся здесь, в
`letopis`, а `archive/`, `data/index.db`, `config.toml`, `.env`, `telegram.session`
и т.п. — в репозитории с данными.

## Устройство

- **`archive/<chat_id>/<YYYY-MM>.jsonl`** — сырые сообщения, источник истины. Файлы
  append-only: синк только дописывает новые сообщения, старые никогда не трогает.
- **`archive/<chat_id>/media/`** + **`media_index.jsonl`** — скачанные файлы и их реестр.
- **`archive/<chat_id>/transcripts.jsonl`** — расшифровки голосовых/кружков.
- **`archive/manifest.json`** — менеджер: какие чаты отслеживаем, каким аккаунтом,
  какие медиа качаем. Переживает пересборку поисковой базы.
- **`data/index.db`** — SQLite-индекс (FTS5): полнотекст по оригиналу И по леммам
  (pymorphy3), поэтому «хостинг» находит «хостингами». В индекс попадают также
  расшифровки голосовых, имена файлов и текст опросов. Производный — пересобирается.
- **`config.toml`** — настройки. **`.env`** — api_id/api_hash.

## Установка

```sh
python3 -m venv .venv && .venv/bin/pip install -e .
.venv/bin/pip install faster-whisper   # опционально: локальная транскрипция
./tg index && ./tg meta
```

## Команды

### Поиск (основное для агента)

| Команда | Что делает |
|---|---|
| `./tg search <слова> [...]` | поиск: `--any` (OR), `--chat`, `--topic`, `--sender`, `--from/--to`, `--around N`, `--count`, `--by-chat/-topic/-sender`, `--rank`, `--json`, `--short N`, `--limit N\|0` |
| `./tg dump --chat X --topic N` | хронологический кусок целиком |
| `./tg context --chat X --id N` | сообщения вокруг заданного |
| `./tg chats` / `./tg topics --chat X` | обзор архива; `./tg status` — состояние |

### Просмотрщики (ручной режим)

| Команда | Что делает |
|---|---|
| `./tg web` | локальный веб: чаты → топики-чипы, бесконечная прокрутка, поиск с фильтрами, прыжок к дате, фильтр по автору (клик по нику), фото/видео инлайн, плеер голосовых с расшифровкой, реплаи с прыжком по треду, ссылки t.me. Порт — в `config.toml [web]` |
| `./tg tui` | то же в терминале: `/` поиск, `g` дата, `s` автор, `o`/`n` старее/новее, `c` контекст, `m` открыть в Telegram, `f` открыть файл, `Esc` назад, `q` выход |

### Качалка и менеджер

| Команда | Что делает |
|---|---|
| `./tg dialogs` | все чаты аккаунта (✓ = уже в архиве) |
| `./tg download --chat <имя\|id\|@user> [--topic N] [--from 2025-01] [--media photo,voice\|all\|none]` | скачать чат/топики и поставить на отслеживание |
| `./tg sync [--chat X] [--media ...]` | докачать новые сообщения всех отслеживаемых чатов |
| `./tg media --chat X --media voice [--from ...] [--limit N]` | докачать файлы для уже скачанных сообщений |
| `./tg transcribe [--provider whisper-local\|telegram\|openai]` | расшифровать голосовые → текст в поиске |
| `./tg untrack --chat X` | снять с отслеживания (файлы остаются) |
| `./tg meta` / `./tg index` | обновить названия / доиндексировать |
| `./tg login --account имя` | авторизовать сессию (телефон/код/2FA) |

Чат указывается как id, алиас из `config.toml`, часть названия, `@username` или ссылка.
Новые сообщения скачиваются со всеми реакциями, опросами и сервисными событиями.

## Транскрипция голосовых

Провайдер в `config.toml [transcription]`:
- **whisper-local** — бесплатно, локально (faster-whisper; модель `small` по умолчанию);
- **telegram** — нативная расшифровка Telegram (нужен Premium на аккаунте);
- **openai** — Whisper API (нужен `OPENAI_API_KEY` в `.env`);
- ~~edge~~ — у Microsoft Edge нет публичного STT (edge-tts умеет только синтез);
  ближайший аналог — Azure Speech (бесплатные 5 ч/мес, нужен ключ), могу добавить.

## Несколько аккаунтов

```toml
[accounts]
default = "telegram.session"
backup  = "sessions/backup.session"
```

`./tg login --account backup` авторизует новую сессию; у `download/sync/dialogs/meta`
есть `--account`. Каждый чат в манифесте закреплён за своим аккаунтом.

## Дорожная карта

- **Этап A — готово**: индекс + поиск + CLI + интеграция с Claude Code.
- **Этап B — готово**: качалка (`download`/`sync`, append-only), медиа по настройкам,
  бэкфилл, транскрипция, менеджер (`manifest.json`), несколько аккаунтов, FloodWait-защита.
- **Этап C — готово**: просмотрщики `tg web` (браузер, медиа) и `tg tui` (терминал).

Идеи дальше: автосинк по расписанию (launchd), OCR картинок, Azure Speech-провайдер,
экспорт выборок.

## Безопасность

`telegram.session` и `.env` дают полный доступ к аккаунту — папку не выкладывать,
в git эти файлы не коммитить.
