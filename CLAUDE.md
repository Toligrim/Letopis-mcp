# Letopis / Letopis-mcp

Движок архива и поиска по Telegram-чатам (`tgarchive/`), поверх которого строится
тонкий MCP-сервер.

## Репозитории

- `origin` → https://github.com/Toligrim/letopis.git — оригинальный движок.
- `letopis-mcp` → https://github.com/Toligrim/Letopis-mcp.git — публичный форк,
  здесь строится MCP-сервер поверх движка. Основная площадка для новой работы.

Оба remote настроены в этой рабочей копии — пушить явно в нужный (`git push origin ...`
/ `git push letopis-mcp ...`), не полагаться на дефолтный.

## Правила

- **Никогда не коммитить**: `config.toml` (содержит реальные `api_id`/`api_hash`
  Telegram-приложений), `data/` (индекс + служебные ledger-данные), `archive/`,
  `*.session`, `.env`. Всё это уже в `.gitignore`. Схема конфига — в
  `config.example.toml`, его и обновлять при изменении формата настроек.
- Перед `git add` в этом репо — всегда `git status` глазами: `config.toml` и
  `data/` не должны туда попасть даже случайно (публичный репозиторий).
- Движок (`tgarchive/`) и данные разделены по дизайну (см. README, раздел
  «Устройство») — MCP-код не должен предполагать, что архив/сессии лежат в этом
  же гите.
